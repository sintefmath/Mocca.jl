A flowsheet by hand ​

A Process turns its device roles and steps into a network of unit models, the device settings of each stage, and a Jutul simulation case. This example builds the four-stage VSA cycle of Haghpanah et al. (2013) directly from that layer, and checks that it gives the same results as the process. A fixed bed is connected to three flow devices:

feed ──V_feed──┐                 ┌──V_product── raffinate
               bottom  Bed  top
extract ──V_vacuum──┘

Each stage of the cycle is a set of device settings (valve open or closed, flow controller rate, boundary pressure profile). Nothing inside the bed changes between stages, so the same bed model can be wired into larger flowsheets. This is the layer to work in when adding a kind of unit, device law or step (see Extending Mocca).

julia
import Mocca
using Mocca.Units

1. The process ​

four_stage_vsa_process builds the flowsheet and its cycle of steps. The run uses steps of 1 s and starts from nitrogen at 1 bar.

julia
ncells = 200
process = Mocca.four_stage_vsa_process(ncells = ncells, timestepping = Mocca.TimeStepping(max_dt = 1.0, first_dt = 1.0),
    initial_state = Dict(:Bed => (pressure = 1bar,)))

2. The same flowsheet by hand ​

A Flowsheet holds a UnitNetwork: the units, the connections between their ports and the boundary conditions of device ports that are not connected. Building the network directly means giving everything the process filled in from the device roles and steps: the bed model, the boundaries, the valve sizes and the device settings of every stage.

julia
gas = Mocca.haghpanah_2013_gas()
feed = Mocca.Feed(gas; composition = [0.15, 0.85], pressure = 1bar)
bed_model = Mocca.fixed_bed_model(gas, feed, Mocca.load_adsorbent("zeolite_13x_haghpanah_2013"),
    Mocca.haghpanah_2013_column(); ncells = ncells, dispersion_velocity = 1.0)

net = Mocca.UnitNetwork()
Mocca.add_unit!(net, :Bed, bed_model)
for d in (:V_feed, :V_product, :V_vacuum)
    Mocca.add_unit!(net, d, Mocca.setup_device_model(gas.names))
