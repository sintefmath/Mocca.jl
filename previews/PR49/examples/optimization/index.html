Optimization of a cyclic process

We optimise the four-stage vacuum swing adsorption (VSA) cycle of Haghpanah et al. (2013) at cyclic steady state: maximise the CO₂ recovery while keeping the purity of the CO₂ product above 90%, by tuning

  • the feed velocity,
  • the low pressure, and
  • the intermediate pressure.

Each evaluation finds the cyclic steady state, starting from the last one, and its gradient with respect to the design variables from adjoints (see the gradients example). A gradient-based optimiser (BFGS within the bounds) then needs far fewer evaluations than a population of designs would. For more details about the VSA modelling, see the Haghpanah cyclic VSA example.

import Mocca
using Mocca.Units

The process and its design variables

A coarse grid keeps the example quick; the bounds are those of Table 5 of the paper.

process = Mocca.four_stage_vsa_process(ncells = 20)
Mocca.add_variable!(process, :v_feed, ("adsorption", :velocity); bounds = (0.1, 2.0), description = "interstitial feed velocity [m/s]")
Mocca.add_variable!(process, :P_L, ("evacuation", :to); bounds = (0.05bar, 0.5bar), description = "low pressure")
Mocca.add_variable!(process, :P_I, ("blowdown", :to); bounds = (0.05bar, 0.5bar), description = "intermediate pressure")

start = Mocca.performance(process)
println("start: purity $(round(100start.purity, digits = 1))%, recovery $(round(100start.recovery, digits = 1))%")
start: purity 79.3%, recovery 36.2%

Run the optimisation

The purity target is a penalty, so the optimum may miss it slightly. The blowdown must end above the evacuation pressure: PL − PI ≤ −0.01 bar.

report(values, r) = println("  ", join(["$k = $(round(v, sigdigits = 4))" for (k, v) in pairs(values)], ", "),
    ": purity $(round(100r.metrics.purity, digits = 2))%, recovery $(round(100r.metrics.recovery, digits = 2))%")
best = Mocca.optimise!(process; maximise = :recovery, at_least = (purity = 0.9,),
